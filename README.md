# 2026 年全国大学生电子设计竞赛 — 智能小车循迹系统

## 📋 项目概述

本项目为 2026 年全国大学生电子设计竞赛（武汉工程大学校内选拔赛）智能小车参赛作品。小车以 **STM32F407VET6** 为主控芯片，**K230 摄像头模组**进行视觉循迹，**JY901S 陀螺仪**实现姿态保持与航向角闭环控制，通过 **TB6612** 双路电机驱动芯片控制双轮差速小车，沿指定路线自动行驶。

### 赛道场地布局

```
                          A ——————————— B
                         /                \
                        /                  \
                       /                    \
                      |                      |
                      |      场地尺寸          |
                      |   220cm × 120cm      |
                      |   圆弧半径 R=40cm     |
                      |                      |
                       \                    /
                        \                  /
                         \                /
                          D ——————————— C
```

| 参数 | 数值 |
|------|------|
| 外框总长度 | 220 cm |
| 外框总宽度 | 120 cm |
| 圆弧半径 | 40 cm |
| 顶部直线 AB 距离 | 100 cm |
| 圆心距边界 | 右侧圆心距右边界 60cm，距下边界 60cm（中轴线上） |

### 竞赛任务

| 任务 | 路线 | 状态 |
|------|------|:----:|
| 任务(1) | A→B 直线行驶 | ✅ 已完成 |
| 任务(2) | A→B→C→D→A 完整一圈 | 🔧 框架已搭建 (~40%) |
| 任务(3) | A→C→B→D→A 交叉路径 | 🔧 初期开发 (~10%) |
| 任务(4) | 多圈连续行驶 + 精确停车 | ⏳ 未开始 (0%) |

### 电机驱动关键参数

| 参数 | 数值 | 说明 |
|------|:----:|------|
| PWM 频率 | 20 kHz | 超声频段，无啸叫 |
| PWM 分辨率 | 100 级 | ARR=99，占空比 1% 步进 |
| 速度输出范围 | -1000 ~ +1000 | 软件钳位，正=前进 |
| 左轮 PID Kp | 0.9 | 速度环比例增益 |
| 左轮 PID Ki | 0.12 | 速度环积分增益 |
| 右轮 PID Kp | 0.8 | 速度环比例增益 |
| 右轮 PID Ki | 0.12 | 速度环积分增益 |
| 角度环 Kp | 0.8 | 航向角比例增益 |
| 角度环 Kd | 0.9 | 航向角微分增益 |
| 编码器分辨率 | 4倍频 | TI12模式，双通道双沿 |

### 通信协议

```
            JY901S 数据帧格式 (11字节)
            ══════════════════════════

    ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
    │ Byte0│ Byte1│ Byte2│ Byte3│ Byte4│ Byte5│ Byte6│ Byte7│ Byte8│ Byte9│Byte10│
    ├──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┤
    │ 0x55 │ Type │  XL  │  XH  │  YL  │  YH  │  ZL  │  ZH  │  TL  │  TH  │ SUM  │
    └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
     帧头    类型    数据低字节  数据高字节  ...  ...  ...  ...  温度低  温度高  校验和

    校验: SUM = Byte0+Byte1+...+Byte9 (低8位)

    数据封装:
    ╔══════╤══════════════╤═══════════════════════╤═════════════════════════╗
    ║ Type │    数据含义    │       计算公式         │         单位             ║
    ╠══════╪══════════════╪═══════════════════════╪═════════════════════════╣
    ║ 0x51 │ 加速度 Ax/Ay/Az│ (short)(XH<<8|XL)/32768×16 │        g             ║
    ║ 0x52 │ 角速度 Gx/Gy/Gz│ (short)(XH<<8|XL)/32768×2000│      deg/s          ║
    ║ 0x53 │ 角度 R/P/Y    │ (short)(XH<<8|XL)/32768×180 │      degree         ║
    ╚══════╧══════════════╧═══════════════════════╧═════════════════════════╝
```
